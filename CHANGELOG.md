# Changelog

All notable changes to `@techcodie/editor` are documented here.

## 1.0.0 - 2026-07-24

### Added

- Supported `DocumentEditor` React component and `createEditor` controller
- Strongly typed, runtime-validated SDK configuration
- Typed instance events and callback configuration
- Lightweight instance-scoped plugin lifecycle
- Theme tokens for color, typography, spacing, radius, shell icons, motion, and shadows
- ESM library output, TypeScript declarations, source maps, and explicit package exports
- React consumer example
- Public API, configuration, event, theming, plugin, feature, migration, and troubleshooting documentation

### Included

- Rich-text editing and formatting toolbar
- Ask Document streaming, retry, cancellation, citations, and insertion
- Selection AI actions and explicit replacement
- Browser-native voice input
- Local PDF, DOCX, TXT, and Markdown knowledge sources
- Responsive document preview
- Command palette, keyboard workflows, error containment, and accessibility support

### Packaging

- Published package identity: `@techcodie/editor`
- React 19 and React DOM 19 as peer dependencies
- Public root entry plus stylesheet entry
- Internal implementation subpaths excluded from package exports
